# Useful Commands

---

## List Sinks

```
pactl list short sinks
```

---

## List Sources

```
pactl list short sources
```

---

## List Modules

```
pactl list short modules
```

---

## Current Default Sink

```
pactl get-default-sink
```

---

## Kill Daemon

```
pkill -f virtual-mic-daemon.sh
```
